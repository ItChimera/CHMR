# CHMR

A desktop video editor for multi-track editing, color grading, chroma keying, audio mixing, and exporting up to 4K locally.

## Getting Started

Download the latest installer for Windows, macOS, or Linux from the **Releases** page and open it.

If you downloaded the repo instead (requires [Node.js](https://nodejs.org) 20+):

- **Windows:** Double-click `Launch-CHMR.bat`.
- **macOS / Linux:**
  ```bash
  npm install
  npm run desktop:setup
  npm run desktop
  ```
